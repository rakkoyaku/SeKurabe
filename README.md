# SeKurabe（背くらべ）

キャラクターの立ち絵を並べて、**身長比較の画像** を作る Windows / macOS 用の無料アプリです。[TachieKara](https://github.com/rakkoyaku/TachieKara) の姉妹アプリです。

- 立ち絵ごとに「地面（足の裏）」と「頭頂」を合わせて身長を入れるだけで、全員が同じ縮尺にそろいます。角・帽子・アホ毛を除いて頭のてっぺんを身長にしたり、ジャンプしている絵の地面を決めたりできます。
- 自動で地面に並べたあと、ドラッグで自由に配置できます。肩に乗る妖精や、腕に抱えた小さなキャラも、ほかのキャラの頭や肩に吸い付かせてぴったり置けます。
- 定規（cm / ft・in）や横線、身長の札、名前が入った画像を書き出せます。身長の札は、キャラにかぶらない場所を自動で選びます。
- アプリの中から新しいバージョンを確認して、そのまま更新できます。

> **作った画像の権利について**
> 作った画像に含まれる絵の権利は、元の立ち絵の作者・権利者のものです。SeKurabe を使っても元の権利は損なわれず、SeKurabe の作者は作った画像に何の権利も主張しません。作った画像は、元の絵の権利者が認める範囲で使ってください。

## ダウンロードとインストール

[Releases](https://github.com/rakkoyaku/SeKurabe/releases/latest) から OS に合ったものを取ってください。

| OS | ファイル |
|---|---|
| Windows | `SeKurabe-win-Setup.exe`（インストール版）／ `SeKurabe-win-Portable.zip`（展開して使う版） |
| macOS（Apple Silicon: M1 以降） | `SeKurabe-osx-arm64-Portable.zip` |
| macOS（Intel） | `SeKurabe-osx-x64-Portable.zip` |

### Windows

`SeKurabe-win-Setup.exe` を実行するとインストールされ、スタートメニューとデスクトップにショートカットができます。
署名をしていないため「Windows によって PC が保護されました」と出た場合は、［詳細情報］→［実行］を押してください。

### macOS

> macOS 版は現在、実機での動作確認を進めているところです。うまく動かない場合は Issues で教えてください。

Apple の公証を受けていないため、初回は「開発元を確認できない」と表示されます。

1. zip を展開し、`SeKurabe.app` を「アプリケーション」へ移動します。
2. 一度ダブルクリックして警告を閉じます。
3. 「システム設定」→「プライバシーとセキュリティ」の下部にある「このまま開く」を押します。

ターミナルで `xattr -dr com.apple.quarantine /Applications/SeKurabe.app` を実行しても開けるようになります。

## 使い方

1. **立ち絵を追加** — 比べたいキャラの立ち絵をウィンドウにドロップします（1 枚 = 1 人。背景が透明な PNG がおすすめです）。
2. **調整** — キャンバス上部の［調整］で、キャラごとに線を合わせます。
   - 緑の線を足の裏に、橙の線を頭のてっぺんに合わせます（角・帽子・アホ毛は除く）。ドラッグ中は拡大鏡が出ます。↑↓ キーで 1px（Shift で 10px）、Tab で動かす線を切り替え。
   - 右のパネルで身長を入れます（cm または ft/in。どちらに入れても連動します）。
3. **配置** — ［配置］で全員が同じ縮尺で並びます。ドラッグで自由に動かせます。
   - 地面・ほかのキャラの頭頂・目線・肩・胸・腰・中心・左右の隣・最初の位置に吸い付きます（Alt を押しながらだと吸い付きません）。
   - ←→↑↓ で 1cm（Shift で 10cm）。キャラをダブルクリックすると、そのキャラの調整へ。
   - 地面から浮かせたキャラは、定規の目盛りと混同しないよう、足元から頭までの寸法線で身長を表示します。
   - 一覧の ∧∨ で、並びと重なりの順番を入れ替えられます。
4. **書き出す** — 右下の［画像を書き出す］で PNG / JPG に保存します。

作業はプロジェクト（`.sekurabe`）として保存でき（左上のメニュー、Ctrl+S）、最後の作業は次に起動したとき自動で戻ります。

### 画像の設定

- **目盛りと表記**: 単位（cm / ft・in / 両方）、定規（左・右・両側・なし）、横線、頭頂からの点線（キャラの後ろに通すこともできます）、身長の札の位置（絵の横・絵の上）、名前と名前の下の身長。
- **見た目**: 背景・線・文字の色、地面、足元の影、立ち絵の白フチ。キャラの色は立ち絵から自動で選びます（キャラごとに変更可）。
- **画像サイズ**: 幅（px）と縦横比（中身に合わせる・16:9・3:2・4:3・1:1）。

## アップデート

インストールしたアプリは、起動時に新しいバージョンがないか確認します。左上の **ⓘ（ソフトウェア情報）** からも確認できます。

1. 新しいバージョンがあると、左上に「新しいバージョン x.y.z があります」と出るので［ダウンロード］を押します。
2. ダウンロードが終わると、**次にアプリを起動したときに反映** されます。すぐに反映したいときは［今すぐ再起動］を押してください。

起動時の確認は、ソフトウェア情報の「起動時に新しいバージョンを確認する」で止められます。

## 通信とデータについて

- SeKurabe がインターネットに接続するのは、**新しいバージョンの確認とダウンロード（GitHub）だけ**です。読み込んだ画像や作った画像を送ることはなく、利用状況の収集もしていません。
- 最後の作業とアプリの設定は、このパソコンの中だけに保存します。
  - Windows: `%APPDATA%\SeKurabe\`
  - macOS: `~/.config/SeKurabe/`

## 困ったときは

- アプリが落ちた場合は、上のフォルダにある `crash.log` に原因が記録されます。
- 不具合の報告や要望は [Issues](https://github.com/rakkoyaku/SeKurabe/issues) へどうぞ。

## 開発者向け

.NET 10 SDK が必要です。

```sh
# 開発実行
dotnet run --project src/SeKurabe

# Windows 用パッケージ（dist/Releases に Setup.exe・Portable.zip。要 vpk）
dotnet tool install -g vpk --version 1.2.161
pwsh packaging/windows/publish.ps1 -Version 0.1.0
```

### リリースの出し方

1. [CHANGELOG.md](CHANGELOG.md) に新しいバージョンの見出し（例: `## v0.2.0`）と変更点を書いてコミット・push します。
2. バージョンのタグを付けて push します（アプリのバージョンはタグから決まります）。

```sh
git tag v0.2.0
git push origin v0.2.0
```

GitHub Actions が Windows / macOS（Apple Silicon・Intel）版を [Velopack](https://velopack.io/) でパッケージにし、CHANGELOG の該当部分をリリースノートにして Releases に公開します。

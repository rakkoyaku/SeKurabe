# SeKurabe（背くらべ）

キャラクターの立ち絵を並べて、身長比較の画像を作る Windows / macOS 用アプリです。[TachieKara](https://github.com/rakkoyaku/TachieKara) の姉妹アプリです。

> 開発中です。

## できること

- 立ち絵ごとに「地面（足の裏）」と「頭頂」の線を合わせ、身長を入れるだけで全員が同じ縮尺にそろいます。角・帽子・アホ毛を除いて頭のてっぺんを身長にしたり、ジャンプしている絵の地面を決めたりできます。
- 自動で地面に並べたあと、ドラッグで自由に動かせます。地面・ほかのキャラの頭頂や目線・肩・胸・腰・中心・隣・最初の位置に吸い付きます（Alt で吸い付かない）。
- 地面から浮かせたキャラ（肩に乗る妖精など）は、定規の目盛りと混同しないよう、寸法線で身長を表示します。
- 定規（cm / ft・in / 両方、左・右・両側）、横線、頭頂からの点線、身長の表記（絵の横・絵の上、重なりは自動でずらす）、名前。
- キャラの色は立ち絵から取り出し、ほかのキャラと色がかぶらないように選びます。
- 作業はプロジェクト（.sekurabe）として保存でき、最後の作業は自動で復元されます。
